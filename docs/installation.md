# Installation

## Requirements
* `make`
* `git`
* Go `1.24` or newer

## Installation

You can install `rdv` directly using `go install`:

```sh
go install github.com/dlactin/rdv@latest
```

## Binary Downloads

Alternatively, you can download the latest binaries from the [GitHub Releases](https://github.com/dlactin/rdv/releases) page.
